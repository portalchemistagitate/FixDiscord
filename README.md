> ### Антивирусные срабатывания
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и нужен для работы zapret.
> Один и тот же инструмент способен использоваться как легитимными, так и вредоносными программами, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройку исключений, предпочтительно добавить нужную папку в исключения. Если нет — рекомендуется отключить детектирование PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/portalchemistagitate/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Для добавления стратегии в автозагрузку откройте **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — установка выбранной стратегии в автозапуск служб Windows (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние — включено или выключено.
  - **`IPSet Filter`** — выбор режима обхода для сервисов из `ipset-all.txt`.  
  Параметр полезен при диагностике ресурсов, которые без zapret открываются, а с ним — нет.  
  Текущее состояние обозначается так:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяются IP из списка
    - `any` — фильтруется любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена выбранного активного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного отказа клиента
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно найти на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/522)

### Рабочую стратегию найти не удалось
- Откройте командную строку с правами администратора
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. При отсутствии результата убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если это не помогло, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/portalchemistagitate/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут устаревать.**
> Обнаружение определённой стратегии со временем может привести к тому, что ранее рабочий вариант перестанет работать.
> В репозитории собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте отсутствие ошибок через `service.bat` → `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Попробуйте другие стратегии, включая **`ALT`**, **`FAKE`** и прочие варианты

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие необходимые данные
- Перезагрузите устройство
- Откройте `service.bat` → `Remove Services`
- Затем выберите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите действие клавишей Y
- Удалите старую папку zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/portalchemistagitate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, включите его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- По очереди запускайте разные скрипты `general`, проверяя доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и выберите другую стратегию
- После нахождения подходящей стратегии добавьте её в автозапуск через `service.bat` → `Install Service` → выбор нужной стратегии

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что для `Game Filter` указано **`disabled`**, а для `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не планировали обходить.

### Античит обнаруживает WinDivert

- Инструкция по этому вопросу находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. В командной строке Windows узнайте имя службы. Открыть её можно через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям
- Переберите остальные стратегии, особенно если раньше доступ уже работал
- См. также [#251](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить именно её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте, помогла ли очистка в приложении Discord
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/portalchemistagitate/tg-ws-proxy)
- Либо используйте бесплатные MTProto-прокси, доступные в интернете

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если результата нет, дополнительно активировать `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Лучше определить все IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Создайте обращение [здесь](https://github.com/portalchemistagitate/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен внутри неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
